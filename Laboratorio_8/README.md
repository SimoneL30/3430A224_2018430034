Es necesario tener instalado C++ para la ejecucion del programa.
El programa consiste en ordenar un arreglo con numeros enteros entre 0 y 10000 generados aleatoriamente.
Se utilizaron dos metodos de ordenamiento Seleccion y Quicksort.
Este programa acepta argumentos por la linea de comando, por lo que el comaando para ejecutar seria:
./Lab8 **<numero_de_elementos_a_ordenar>** **<opcion_mostrar_vectores>**
