Es necesario tener instalado C++ para la ejecucion del programa. 
El programa consiste en el ingreso y busqueda de un numero dentro de un arreglo (Tabla Hash) con numeros enteros generados aleatoriamente. 
Se utilizaron 3 metodos para la resolucion de colisiones: Lineal (L), Cuadratica (C) y Doble Hash (D). 
Este programa acepta argumentos por la linea de comando, por lo que el comando para ejecutar seria: ./Lab9 <tamaño_de_tabla_hash> <metodo_resolucion_colisiones>
